# О себе — Кузнецова Светлана

Лабораторная работа № 3. Вёрстка макета с помощью Flexbox и Grid.
Страница из ЛР №2, дополненная по заданию ЛР №3.
Тема варианта 18 — «Космический энтузиаст и астроном-любитель»
(тёмная тема по умолчанию, звёздное небо и мерцание).

## Структура

- `index.html` — разметка страницы
- `style.css` — внешние стили
- `images/myphoto.jpg` — фото для аватара

## Что добавлено в ЛР №3

| Требование | Реализация |
|---|---|
| Flexbox: адаптивное горизонтальное меню | `nav .nav-list` — `display: flex; flex-wrap: wrap`, на мобильных столбиком |
| Flexbox: карточки в ряд | «Объекты для наблюдения» — 6 карточек (название, созвездие, яркость), `<article>` + `<dl>` |
| Grid: дашборд | «Космические факты» — 3 блока (факт, число, иконка), `display: grid` |
| Адаптивность по варианту | Карточки 3 / 2 / 1 в ряд, Grid 3 / 2 / 1 колонок |
| Медиа-запросы | `max-width: 1023px` (планшет), `700px` (боковая панель), `599px` (мобильные) |
| Без горизонтальной прокрутки | `box-sizing: border-box`, `min-width: 0`, `flex-wrap`, `overflow-wrap`, `max-width: 100%` у изображений |
| Контрастность ≥ 4.5:1 | Расчёт ниже |

## Исправления по замечаниям к ЛР №2

1. `.star-field`: убран конфликт inline-стиля и CSS. Контейнер теперь
   `position: fixed` на весь экран (`top/right/bottom/left: 0`),
   inline-стиль содержит только `overflow: hidden`.
2. `:hover` на «Проекты»: правило через `body:has(#projects:hover)` —
   меняется `opacity` фона `.stars`, слои раздвигаются через `scale`,
   контейнер мелких звёзд тоже.
3. Добавлены `a:focus` и `button:focus` с заметной обводкой,
   у полей формы вместо `outline: none` — видимая обводка.
4. Анимации разделены: `twinkle-bg` для фона и `twinkle-star` для `.star`.
   Hover меняет `opacity` у родителя, поэтому анимация его не перекрывает.
5. Проверка валидности: HTML — W3C Markup Validator, CSS — W3C CSS Validator.
   Исправлено: ссылка на Википедию закодирована, заголовок в `<aside>`
   приведён к `h2`, убран `inset` (заменён на `top/right/bottom/left`).
